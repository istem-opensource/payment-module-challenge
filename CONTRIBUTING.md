# Contribution Guidelines
 
Thank you for your interest in contributing to
the I-STEM Code Exchange Hub.
 
## 1. Register for the Challenge
 
Register your interest through the official
I-STEM Code Exchange portal.
 
## 2. Understand the Requirements
 
Review the following before development:
 
- Payment Module Problem Statement.
- Sandbox API and FBR Schema Reference.
- Functional and technical requirements.
- Expected deliverables.
 
## 3. Fork the Repository
 
Contributors must fork the official repository
into their own GitHub account.
 
External contributors are not granted direct
write access to the official repository.
 
## 4. Create a Development Branch
 
Develop your solution in a separate branch.
 
Do not attempt to push changes directly
to the official main branch.
 
## 5. Prepare Your Solution
 
Include:
 
- Complete source code.
- README and setup instructions.
- System architecture.
- API documentation.
- Implementation SOP.
- Test cases and evidence.
- Demonstration details.
- Licence and dependency information.
 
## 6. Security
 
Use synthetic data and approved sandbox
credentials only.
 
Never commit passwords, API keys, private tokens,
production credentials or confidential data.
 
## 7. Submit a Pull Request
 
Create a Pull Request against the designated
official repository branch.
 
Complete the Pull Request template and provide
the required technical documentation.
 
## 8. Contributor Declaration
 
Contributors must have the necessary rights
and authority to share their submitted code.
 
The approved Contributor Licence Agreement
must be completed before merging.
 
## 9. Review Process
 
Contributions are subject to:
 
- Automated validation checks.
- Technical review.
- Security review.
- Maintainer approval.
 
Submission of a Pull Request does not guarantee
selection, approval or acceptance.
 
## 10. Institutional Adoption
 
Approved contributions may be published for
institutional discovery and potential reuse.
 
Adopting institutions remain responsible for
their local testing, security assessment,
configuration, approval and deployment.
